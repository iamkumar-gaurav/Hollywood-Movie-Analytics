## 📖 About The Project

This project was completed during my journey through the **Google Data Analytics Professional Certificate**.

The objective was to perform an end-to-end analysis of the **Top 1000 Highest Grossing Hollywood Movies** dataset and uncover meaningful business insights through data cleaning, exploratory analysis, visualization, and storytelling.

The project combines **Microsoft Excel** for data preparation and **Tableau** for dashboard development.

---

## 🎯 Business Problem

The entertainment industry generates billions of dollars annually. Understanding movie performance trends can help studios, distributors, and investors make informed business decisions.

### Key Questions Explored

* Which distributors dominate box-office revenue?
* Which genres consistently perform well?
* How do domestic and international revenues compare?
* Which years produced the highest-grossing movies?
* What patterns exist among successful films?
